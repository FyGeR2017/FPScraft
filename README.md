# FPScraft Overlay

Точный технический оверлей телеметрии на **Rust** для Windows (`eframe` / `egui`, `nvml-wrapper`, `sysinfo`, `windows-sys`) с отдельным окном настроек.

## Возможности и дизайн

- **Единая поверхность**: нейтральный тёмный фон с настраиваемой прозрачностью, радиусом `2 px`, разделителями `1 px` без вложенных карточек, свечения и градиентов.
- **Сигнальная палитра**: 1 акцент (`#38BDF8`) и 2 сигнальных цвета (жёлтый `#EAB308` и красный `#EF4444` только при превышении порогов температуры/нагрузки/памяти или просадках FPS).
- **Иерархия и табличная типографика**: моноширинный шрифт (`JetBrains Mono` / `IBM Plex Mono` / `Cascadia Mono`), 3 размера текста и выравнивание чисел по правому краю.
- **График FPS**: тонкая линия `1.2 px` без заливки на сетке с подписями `60 / 144 / 240` и линией порога `1% Low`.
- **Два режима**:
  - **Полный**: заголовок с активным процессом и индикатором `F8`, FPS (`1% Low`, кадр в `мс`, график), CPU (температура, загрузка, частота, мощность, сегментные полоски по ядрам), GPU (температура, загрузка, частота, мощность, кулер, `VRAM`), ОЗУ (`занято / всего (%)`), сеть (`↓ / ↑`), аптайм и свободное место на диске `C:`.
  - **Угол**: компактная однострочная панель с `FPS`, `1% Low`, `CPU °C` и `GPU °C`.
- **Отдельное окно настроек (`⚙` или `F7`)**: три категории (`Показатели`, `Горячие клавиши`, `Вид и пороги`) — включение/отключение любой метрики, переназначение всех глобальных клавиш, настройка прозрачности фона и порогов цветных предупреждений.
- **Системный трей**: после запуска утилита остаётся в области уведомлений. Меню трея позволяет показать/скрыть оверлей, открыть настройки, включить автозапуск и выйти. Кнопка `×` на оверлее сворачивает его в трей.

## Установка

Готовый установщик: `dist\FPScraft-Setup.exe` (или `dist\FPScraft-Setup-0.1.1.exe`).

- Устанавливается в `%LOCALAPPDATA%\FPScraft` без прав администратора.
- Ярлык на рабочем столе — по желанию.
- Автозапуск при входе в Windows — по желанию (можно позже переключить в меню трея).
- Установщик сам закрывает запущенный FPScraft перед обновлением и удаляет автозапуск при удалении.

Собрать установщик заново:

```powershell
winget install -e --id JRSoftware.InnoSetup
powershell -ExecutionPolicy Bypass -File build-installer.ps1
```


## Горячие клавиши по умолчанию (переназначаются в настройках)

- `F1` — показать/скрыть подсказку клавиш на оверлее (также видна при наведении на статус `F8`)
- `F7` — открыть/закрыть окно настроек
- `F8` — режим **клик-сквозь** (мышь проходит в игру; когда выключен, панель можно перетаскивать)
- `F9` — переключение режима (**Полный ↔ Угол**)
- `F10` — скрыть / показать оверлей
- `F11` — переместить оверлей в следующий угол экрана
- `F12` — закрыть утилиту

## Сборка и запуск

```powershell
cargo run --release
```

Или собрать `target\release\fpscraft.exe`:

```powershell
cargo build --release
```
